# MG20 — хвостовое оперение, RevC (эскизно-конструктивная ревизия)

**Важно:** это предварительная параметрическая модель. Она не предназначена для изготовления и полётов без расчёта прочности, проверки аэродинамических нагрузок, жёсткости, флаттера, центра тяжести и привязки к реальной геометрии фюзеляжа. Файлы нервюр — **пробные шаблоны для проверки размеров и сборки**, а не согласованный производственный комплект.

## Что изменилось после RevB

1. Вместо плоских «плит» использованы симметричные профили NACA 0010 для стабилизатора и NACA 0009 для киля (профили аппроксимированы полилиниями для надёжного STEP).
2. Разделён руль высоты на левую и правую половины; центральный промежуток 30 мм.
3. Шесть аэродинамических тел и отдельный сборный эскиз каркаса: 32 нервюры + 12 объёмных полок лонжеронов = 44 детали.
4. Сформированы DXF-контуры каждой нервюры, рассортированные по материалу.
5. STEP проверены повторным импортом через OpenCascade (счёт тел, ненулевой объём, валидность BRep). Проверка импорта **внутри КОМПАС-3D не проводилась**.

## Геометрия, мм

| Узел | Размер |
|---|---|
| Стабилизатор: размах | 1000 |
| Стабилизатор: хорда у корня / на конце | 200 / 120 |
| Площадь плана стабилизатора (включая руль) | 0,160 м² |
| Киль: высота | 420 |
| Киль: хорда у основания / вверху | 300 / 180 |
| Площадь плана киля (включая руль) | 0,1008 м² |
| Относительная толщина профилей | 10% горизонтальное / 9% вертикальное |
| Хорда рулей | приблизительно 30% местной хорды |
| Щель между неподвижной и подвижной частью | 2 (по продольной координате X) |
| Промежуток между половинами РВ | 30 |
| Основание киля относительно плоскости симметрии стабилизатора | Z=15 |
| Условное плечо хвоста, принятое в RevB | 800 — **не проверено и не задано в сборке** |

Система: **X** к хвосту, **Y** вправо, **Z** вверх. Плоскость симметрии стабилизатора Z=0. Габарит киля: Z=15…435. Положение на фюзеляже пока не зафиксировано.

## Предварительная силовая схема

- Стабилизатор и киль: по два продольных ряда полок на каждой неподвижной поверхности, на **30%** и **57%** местной хорды. Геометрия полок выполнена в STEP.
- Основные полки: номинальный размер заготовки **5×4 мм** (ширина по хорде × толщина по профилю). Задние полки: **3×3 мм**. Заготовки должны подгоняться по местной толщине профиля и к стыку с фюзеляжем. Порода древесины и фактическое сечение должны быть утверждены расчётом.
- Нервюры фиксированных поверхностей: бальза 3 мм; около корня фанера 2 мм.
- Нервюры рулей: бальза 2 мм. Узлы петель и кабанчиков требуют местных усилений из фанеры, которых **нет** в этой модели.
- Силовые стенки между полками, передняя кромка, обшивка/кручение, задняя кромка, петли, сервоприводы, соединитель половин РВ, подкосы/крепление на фюзеляж пока **не смоделированы**. Считать каркас с готовыми нервюрами и полками завершённым нельзя.
- В местах пазов оставлен **0,2 мм суммарный геометрический припуск по ширине** относительно номинальных реек. Это не учёт ширины лазерного реза. Перед изготовлением обязательно вырезать один тестовый образец.

## Файлы

- `step/MG20_RevC_Airfoil_6Solids.step` — внешний габарит шести объёмных деталей.
- `step/skins/*.step` — шесть отдельных STEP: удобнее проверять в КОМПАС с одной детали.
- `step/MG20_RevC_Skeleton.step` — каркас: нервюры и полки, **без обшивки**.
- `step/HS_R_Fixed_AP203.step` — пробная отдельная деталь в альтернативной схеме STEP AP203 для диагностики КОМПАС.
- `step/HS_R_Fixed_AP214IS.step` — пробная отдельная деталь в альтернативной схеме STEP AP214IS.
- `cut/Tail_Ribs_ply2_1to1.dxf` — 3 нервюры из фанеры 2 мм (по 2 корневых стабилизатора и 1 корневая киля).
- `cut/Tail_Ribs_balsa3_1to1.dxf` — 13 нервюр из бальзы 3 мм.
- `cut/Tail_Ribs_balsa2_1to1.dxf` — 16 нервюр рулей из бальзы 2 мм.
- `previews/MG20_Tail_RevC_geometry.png` — габариты, план и боковой вид.
- `generate.py` — воспроизводимый генератор для CadQuery + OpenCascade + shapely + ezdxf.
- `parameters.json` — входные параметры.
- `verification.json` — параметры и результаты машинного контрольного импорта STEP.

**DXF** содержат геометрию в миллиметрах в масштабе **1:1**. Слой `CUT` — замкнутые контуры; слой `ENGRAVE_ID` — подписи, их нельзя направлять как режущий контур. Чертежи не содержат поправки на ширину пропила лазера и не учитывают деформацию/усадку материала.

## Проверка КОМПАС

1. Сначала импортировать `step/skins/HS_R_Fixed.step`, выбрать показывать тело, выполнить «Показать всё».
2. Если модель пустая, импортировать `step/HS_R_Fixed_AP203.step`, затем `step/HS_R_Fixed_AP214IS.step`. Сравнить с тем, как импортируется корректное крыло.
3. Если хотя бы один вариант работает, проверять полную сборку `step/MG20_RevC_Airfoil_6Solids.step`.
4. Геометрия валидируется OpenCascade, но это **не гарантия поддержки импорта конкретной версии КОМПАС**.

## Что обязательно нужно для следующей ревизии

- Координаты хвостовой части фюзеляжа и реальные точки крепления стабилизатора/киля.
- Положение крыла и центра тяжести, площадь/САХ крыла и фактическое плечо хвоста.
- Расчётная максимальная скорость и манёвренные перегрузки для проверки полок, стенок, рулей и узлов петель (особенно флаттера).
- Конструкция и шарниры рулей с проверкой полного отклонения без столкновения: **на RevC щель условная и кинематика не проверялась**.

## Дополнительные таблицы и пробный образец

- `Cut_Parts_List.csv` — поштучный список 32 нервюр с материалом и положением.
- `Spar_Caps_List.csv` — 12 полок лонжеронов, номинальные сечения и длины. **Прочность не подтверждена.**
- `Hinge_Stations_PRELIMINARY.csv` — предварительные девять позиций осей петель, не для окончательной разметки без расчёта.
- `cut/Fit_Test_Slots_5mm_3mm.dxf` — тестовая планка с пазами 5,0 / 5,1 / 5,2 / 5,3 мм и 3,0 / 3,1 / 3,2 / 3,3 мм. Проверить в фактическом материале и на фактическом станке, а уже затем принимать размеры всех пазов.
- `previews/MG20_Tail_RevC_3D.png` — предварительная 3D-визуализация.

Сборка с подвижными рулями не просчитана на кинематическую совместимость: их передние кромки пока с прямым срезом, и для рабочего отклонения понадобится профильная фаска/скругление и подбор петли.

Для воспроизведения файлов: `python generate.py`, затем `python manufacture_extras.py` и, при желании, `python render_preview.py`.
